## 给博客新增「RMMZ 插件」独立板块

### 结论
可行。新建一个与 `posts` 完全隔离的 `mzplugin` 内容集合 + 列表页 + 详情页，从顶部导航栏进入。因为首页分页、归档、RSS、`api/allPostMeta.json` 都只读 `posts` 集合，**不进主页/归档/RSS 是零改动自动达成的**。

### 数据层
- `src/content/mzplugin/<插件名>.md`，一个插件一个 md，正文写说明文档。
- 改 `src/content.config.ts`：新增 `MzPluginData` / `MzPluginDownload` / `MzPluginRequire` 类型 + `mzpluginCollection`，并加入 `collections` 导出。
- frontmatter 字段（除 title/published/version/description 外均可选带默认值）：
  - 基础：`title`、`published`、`updated`、`version`、`description`、`image`、`order`、`draft`
  - 标签与状态：`tags`、`status`（maintaining / wip / paused / archived，写别的原样中性灰显示）
  - 兼容与依赖：`engine`（默认 `["MZ"]`）、`mzVersion`、`requires: [{name, url}]`、`notes`
  - 下载：`downloads: [{label, url, icon, code, size, file}]`
  - 其他：`lang`、`comment`
- `src/utils/content-utils.ts` 加 `getSortedMzPlugins()`：`order` 降序置顶 → `updated ?? published` 降序 → 标题兜底；生产环境过滤 `draft`。

### 路由层
- `src/pages/mzplugin/index.astro`：标题面板 + 工具条（搜索、状态筛选、标签筛选、排序切换）+ **一行一条的列表**（缩略图 / 名称+版本徽标+状态徽标 / 简介 / 更新日期·适配引擎·标签 / 下载按钮+查看详情）+ 空态。筛选与排序用一个原生自定义元素 `<mzplugin-list>`，照 `project-filter` / `booknav-list` 的既有写法，不引入框架。
- `src/pages/mzplugin/[slug].astro`：返回列表 → 标题+版本+状态 → 日期+标签 → 下载按钮组（网盘含提取码、站内文件直接下载、外链）→ 兼容性信息块（引擎/版本、前置插件、注意事项）→ 预览图（灯箱）→ 正文（`<Markdown>`，自带 `data-pagefind-body`，Pagefind 索引整个站点根目录所以搜索自动生效）→ 可选评论区（`<Comment customPath=... title=... />`，不改评论组件）。

### 组件与工具
- 新增 `src/components/pages/mzplugin/PluginListItem.astro`（列表行）、`PluginDownloads.astro`（下载按钮组，列表与详情共用）。
- 新增 `src/utils/mzplugin-utils.ts`：状态元数据（文案+图标+配色）、`formatVersion`、`formatEngineLabel`、`resolveDownloadTarget`（站内路径自动补 `BASE_URL` 并加 `download` 属性，外链自动新窗口）。
- 图标与封面解析直接复用 `src/utils/projects-utils.ts` 里实现上通用的 `resolveLinkIcon` / `resolveProjectImage*`，不复制。

### 配置层
- 页面开关：`src/types/siteConfig.ts` 的 `pages` 加 `mzplugin: boolean`，`src/config/siteConfig.ts` 加 `mzplugin: true`（同时白得 `PUBLIC_PAGES_MZPLUGIN` 环境变量开关）。
- 新增 `src/types/mzpluginConfig.ts` + `src/config/mzpluginConfig.ts`（页面标题、描述、搜索占位、空态、排序文案、状态文案，中文），并在 `src/config/index.ts` 与 `src/types/config.ts` 登记导出。这样**不动 i18n 的 6 个语言文件**；已存在的「全部」「搜索无结果」复用现有 key。
- 导航栏由你手动加（我给片段）：`LinkPresets.MzPlugin = { name: "插件", url: "/mzplugin/", icon: "material-symbols:extension", pageKey: "mzplugin" }`，再在 `getDynamicNavBarConfig()` 里 `links.push(LinkPresets.MzPlugin)` 或塞进某个 `children`。

### 站内文件托管
约定 `public/downloads/<插件名>/<文件>`，md 里写 `url: /downloads/<插件名>/<文件>` 即渲染成直接下载按钮；外链网盘照旧写完整 URL。提醒：Cloudflare Pages 单文件 25MB 上限。

### 脚手架
新增 `scripts/new-mzplugin.js` + `pnpm new-mzplugin <标题> [文件名]`，仿 `new-post.js` / `new-dynamic.js`：按时区生成时间戳、中文标题转拼音 slug、写带注释的 frontmatter 骨架。

### 示例条目
新增 `src/content/mzplugin/example-plugin.md`（`draft: true`），开发模式可见作样式参考，生产构建自动隐藏，你随时可删。

### 改动清单
新增：`src/content/mzplugin/`、`src/pages/mzplugin/{index,[slug]}.astro`、`src/components/pages/mzplugin/{PluginListItem,PluginDownloads}.astro`、`src/utils/mzplugin-utils.ts`、`src/config/mzpluginConfig.ts`、`src/types/mzpluginConfig.ts`、`scripts/new-mzplugin.js`
修改：`src/content.config.ts`、`src/utils/content-utils.ts`、`src/types/siteConfig.ts`、`src/config/siteConfig.ts`、`src/config/index.ts`、`src/types/config.ts`、`package.json`
不动：主页分页、归档、RSS/atom、`api/allPostMeta.json`、i18n 语言文件、评论组件、`projects` 集合

### 验证
`pnpm check` → `pnpm type-check` → `pnpm dev` 目测列表/筛选/排序/详情/深链 → `pnpm build` 确认 Pagefind 索引到插件页。
